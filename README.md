## Getting Started

### Prerequisites

- A modern web browser
- Git (for version control)

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/jweder07/jweder07.dev.git
cd jweder07.dev
```

2. Open `index.html` in your browser or use a local server:
```bash
# Python 3
python -m http.server 8000

# Or with Node.js
npx http-server
```

3. Visit `http://localhost:8000` in your browser

## GitHub Pages Deployment

This website is set up to automatically deploy via GitHub Pages. Every push to the `main` branch will automatically update the live site at:
[https://jweder07.dev](https://jweder07.dev)

### Enable GitHub Pages:

1. Go to your repository settings
2. Navigate to "Pages" section
3. Set source to `main` branch
4. Your site will be published at `https://username.github.io/repo-name`

## Customization

To customize this site:

1. **Update content** - Edit `index.html` with your own content
2. **Modify styles** - Adjust colors and layout in `css/style.css`
3. **Add functionality** - Enhance features in `js/script.js`
